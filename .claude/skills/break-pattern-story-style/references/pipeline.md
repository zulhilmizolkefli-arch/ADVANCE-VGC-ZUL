# Break Pattern Story Style: pipeline and numbers

## Project layout
```
<Project>/
  master/index.master.html     edit THIS (62.26 s master, synced to the un-squeezed VO)
  master/index.master16.html   generated by make_landscape_master.py (16:9)
  hf/index.html                generated by retime_build.py (fast cut). Do not hand-edit unless you stop using retime
  hf/assets/{char,footage,ui,video,audio}/
  audio/                       VO_*_EDITED.wav, VO_*_FAST.wav, vo_cues.json, retime_map.json, stems, mix_fast.wav
  scripts/                     see SKILL.md
```

## Data flow
```
vo_raw.m4a ─transcribe.py─> transcript_raw.json ─edit_vo.py─> VO_EDITED.wav + vo_cues.json (tidy, demo gap reserved)
VO_EDITED.wav ─edit_vo_fast.py─> VO_FAST.wav + retime_map.json {xs, ys, new_total, demo_new_start, cs_pre, cs_src}
master/index.master.html + retime_map ─retime_build.py─> hf/index.html   (scenes, <video>, <audio>, every tween remapped)
retime_map + VO_FAST + song + case-study ─make_audio_fast.py─> audio/mix_fast.wav  -> hf/assets/audio/mix.wav
```
`retime_build.py [master] [target]` takes optional paths, and is reused for 16:9.

## Squeeze rules (`edit_vo_fast.py`)
A silence is anything below −38 dBFS (10 ms RMS). Gaps of ≥ 1.0 s go to 0.26 s, ≥ 0.5 s to 0.20 s and ≥ 0.25 s to 0.14 s; anything shorter is kept. The lead is 0.12 s and the tail 1.55 s. The demo gap is set to exactly the case-study sentence plus 0.20 s before and 0.22 s after. Crossfades are 3 ms and cuts are made inside the silence only.

## Audio (`make_audio_fast.py`)
- Song "the gonk" (about 105 BPM, user-confirmed non-copyright). It is cut so that `GONK_DROP = 38.35` s in the track lands on `TM(23.65)` (the logo). Fade-in 0.9 s, fade-out 1.4 s. About −21 dB under the voice while speaking, ducked by the voice and the demo audio, with a −3 dB EQ dip at 2.2 kHz. The drop section is held 0.6× for about 4 s so the voice stays clear. Check the song's L/R correlation; it should be about +0.99, with no inverted channel.
- A synth fallback (84 BPM, Am F C G pad, pluck and bass) exists in the script if no song is supplied.
- SFX are placed at master times and mapped through `TM()`: pops (small), slams (55–100 Hz, 0.3–0.4 s) on punchlines, dings, and whooshes on wipes only.
- Two-step loudness: measure integrated loudness, apply linear gain to −14 LUFS, then `alimiter` at 0.89.

## 16:9 rebuild (`make_landscape_master.py`)
Every scene is re-laid out for 1920×1080: the character at the side, content beside it, the workflow as a 3 + 2 grid, the stairs left to right and the demo card 960 px tall on the right. Panels and nodes are scaled 0.72–0.87. Run `audit_layout.py hf16` (sides ≥ 80, top and bottom ≥ 50).
