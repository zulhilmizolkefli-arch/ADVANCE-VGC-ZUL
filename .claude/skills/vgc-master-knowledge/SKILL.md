# VGC Master Knowledge

The full source is `references/VGC_MASTER_KNOWLEDGE.md` (Bahasa Melayu, 4 parts). Read the part you need before acting. Follow it as written; do not summarise it away or invent rules it does not contain.

| Task | Read |
|---|---|
| Script, hook, copy, CTA, angle | Part 1 §2–5 (brand profile, marketing thinking, tone, **formulas**, hand-off format) |
| Plan or brief a video | Part 1 §6 (workflow, brief hand-off template) + Part 2 §1 |
| Edit decisions (colour, type, layout, motion, audio, export) | Part 2 |
| Review or QC an export | Part 3 (checklist), then Part 1 §6G for revision format |
| Collect inputs from a student | Part 4 (template input) |

## Non-negotiables from the source
- **Exact formula definitions.** HKA = Hook jual apa → Killer USP → Action. HIKA = Hook Problem → Intro Product → Killer USP → Action. SEEIUWTOA = Situation → Exaggerate → Educate → Intro Product → USP → Who → Trust → Offer → Action. Never change what an acronym stands for.
- **TCS (Teknik Campak Skrip):** its official steps are not in this file. Never invent a breakdown of T/C/S; ask for Coach Am's TCS module.
- **Honesty:** no invented testimonials, prices, offers, scarcity, results or "100% berkesan". When Trust or Offer is missing, write `[BUKTI DIPERLUKAN]` / `[OFFER BELUM DISAHKAN]` and ask.
- **Student's own brand:** use the student's facts, voice and assets, never the instructor's profile. Ask at most three questions per round.
- **Script delivery:** objective + chosen formula in one line, then a clean spoken script with no formula labels in the dialogue. Visual directions go separately. End with the unconfirmed facts and one next step.
- **Separate the request types:** analyse, write, edit and review are different requests. Don't turn an analysis into edits without being told.
- In this repo, building and rendering use the style skills and HyperFrames (see `CLAUDE.md`). Read the knowledge first, then the chosen style's `SKILL.md`.
